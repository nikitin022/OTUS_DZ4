# «Капля» — PWA для доноров крови

Прогрессивное веб-приложение, которое показывает центры крови на интерактивной карте,
ведёт живую ленту потребностей и отправляет донорам push-уведомления, когда в их городе
нужна именно их группа крови.

## Технологический стек

- **React 18 + TypeScript + Vite** — UI-фреймворк, сборка;
- **Tailwind CSS** — стилизация (Minimalist, mobile-first от 320px, WCAG AA);
- **Leaflet + react-leaflet (OpenStreetMap)** — карта центров крови;
- **TanStack Query** — серверное состояние, автообновление ленты, офлайн-кэш;
- **React Router v6** — навигация;
- **vite-plugin-pwa (Workbox)** — Service Worker, manifest, установка на устройство;
- **Web Push API** — уведомления по профилю донора;
- **Vitest + React Testing Library** — тестирование.

Данные в MVP — mock-слой на localStorage с контрактом API из ТЗ (раздел 8).

## Ключевые функции MVP

1. **Профиль донора** — группа крови, резус, радиус 1–500 км, согласия на гео/push;
2. **Карта центров** — маркеры, «открыто/закрыто», поиск, фильтры, карточка центра, маршрут;
3. **Живая лента потребностей** — заявки с прогрессом и срочностью, автообновление 30–60 с;
4. **Push-уведомления** — по группе крови и радиусу, с дедупликацией;
5. **Запись на донацию и история** — слоты, контроль интервала ≥ 60 дней, статусы.

## Структура проекта (план)

```
ДЗ4/
├── docs/                        # Проектная документация
├── public/                      # Иконки PWA, манифест-ассеты
└── src/                         # Код приложения (создаётся на следующих шагах)
    ├── app/                     # Роутинг, провайдеры
    ├── components/              # UI-компоненты
    ├── features/                # Функциональные модули (map, feed, profile, ...)
    ├── api/                     # ApiClient-интерфейс и mock-реализация
    ├── types/                   # Модели данных (Донор, Центр, Заявка, ...)
    └── lib/                     # Утилиты
```

## Запуск (после инициализации кода)

```bash
npm install
npm run dev      # дев-сервер Vite
npm run build    # прод-сборка + PWA
npm run test     # Vitest
```
